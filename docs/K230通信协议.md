# K230 → STM32 通信协议

适用：`Gimbal_2026`（云台主控板）与 K230D BOX 之间的 UART 链路。

## 物理层

| 项目 | 值 |
|---|---|
| 接口 | USART2 |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验 | 无 |
| 停止位 | 1 |
| 流控 | 无 |
| K230 侧 | UART2，GPIO44 = TX，GPIO45 = RX |

## 帧格式（13 字节定长，大端序）

| 偏移 | 长度 | 字段 | 类型 | 说明 |
|---|---:|---|---|---|
| 0 | 1 | `head0` | uint8 | 固定 `0xAA` |
| 1 | 1 | `head1` | uint8 | 固定 `0x55` |
| 2 | 1 | `type` | uint8 | 固定 `0x01` |
| 3 | 1 | `length` | uint8 | 固定 `0x08` |
| 4 | 2 | `x` | int16 BE | 人体框中心像素 X |
| 6 | 2 | `y` | int16 BE | 人体框中心像素 Y |
| 8 | 2 | `reserved` | uint16 BE | 固定 0 |
| 10 | 2 | `reserved` | uint16 BE | 固定 0 |
| 12 | 1 | `checksum` | uint8 | 前 12 字节逐字节异或 |

### 坐标语义

- 坐标系：检测画面像素坐标，原点**左上角**，x 向右增、y 向下增。
- 画面分辨率：**1280 × 960**（与 K230 侧 `rgb888p_size` 一致）。
- 画面中心：`(640, 480)`。
- STM32 侧换算：`offset_x = x - 640`，`offset_y = y - 480`，
  再归一化为 `offset / 640 × 100`（水平）与 `offset / 480 × 100`（垂直），
  取值 -100 ~ +100。

### 丢失约定

`x < 0` 或 `y < 0` 表示**这一帧没有检测到人**。
K230 侧实测发送 `(-1, -1)`。

| 情况 | K230 行为 | STM32 行为 |
|---|---|---|
| 检测到人 | 每 30 ms 发一帧真实坐标 | 跟踪 |
| 没检测到人 | 每 200 ms 补发一帧 `(-1,-1)` | 立即判丢失，保持角度 |
| K230 死机/断线 | 不发任何数据 | 300 ms 超时后判丢失，保持角度 |

> 两种丢失路径都要覆盖：只看 `detected` 位的话，K230 完全断电时就发现不了。

## 校验示例

发送 `x = 640`、`y = 480`、保留字段全 0：

```
AA 55 01 08  02 80  01 E0  00 00  00 00  [XOR]
```

异或结果 = `AA^55^01^08^02^80^01^E0^00^00^00^00` = `0xE5`（示例值，以实际计算为准）。

## 解析器行为

STM32 侧解析器（`modules/vision_protocol.c`）按以下策略工作：

1. 在环形缓冲里滑窗寻找 4 字节帧头，**失配只前进 1 字节**（不是跳整帧）；
2. 攒够 13 字节后校验前 12 字节异或；
3. 校验失败**只丢 1 字节**重新同步（残帧里可能藏着下一帧帧头）；
4. 校验通过才整帧出队；
5. 没找到帧头时保留末尾 3 字节，防止帧头跨缓冲边界被丢掉。

因此即使中间丢字节、多字节、混入噪声，也能自动恢复同步。

## 与 K230 脚本的对应

K230 侧脚本：`k230/person_detection_gimbal.py`（本工程归档副本）。

对应代码：

```python
class GimbalLink:
    HEADER = (0xAA, 0x55, 0x01, 0x08)
    LOST_PX = -1
    ...
    frame = bytearray(self.HEADER)
    frame += struct.pack(">hhHH", x, y, 0, 0)   # 大端 int16 ×2 + uint16 ×2
    checksum = 0
    for value in frame:
        checksum ^= value
    frame.append(checksum & 0xFF)
```

`struct.pack(">hhHH", ...)` 的 `>` 就是大端，与 STM32 侧 `(data[0]<<8)|data[1]` 对应。

## 修改协议时的约束

1. 必须**同时**改 K230 脚本、`config/vision_config.h`、本文档；
2. 帧长变化要改 `VISION_FRAME_LEN`，并检查解析器里的 `VISION_CHECKSUM_INDEX`；
3. 分辨率变化要改 `VISION_IMAGE_WIDTH_PX/HEIGHT_PX`，否则偏差会整体偏移；
4. 不允许去掉异或校验（没有校验就无法在噪声中重同步）。

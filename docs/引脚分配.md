# Gimbal_2026 引脚分配

主控：STM32F103C8T6（LQFP48，插在板中央两个长排母上，旁边丝印「调试接口」）

> **本表按「视觉云台系统」PCB 丝印填写，是唯一的引脚依据。**
> 代码里的对应关系全部来自 `config/pin_config.h`，两者必须一致。
>
> 已确认的硬件事实：
> - K230 串口 4 针：`5V / GND / PA3 / PA2`，丝印上方标 `RX TX`
> - 云台(上) 3 针：`GND / 5V / PA8`
> - 云台(下) 3 针：`GND / 5V / PA11`
> - 蜂鸣器 3 针：`3V3 / PB4 / GND`
> - 板间通信 4 针：`PA9 / PA10 / GND / 3V3`，丝印标 `TX RX`
> - 5V 供电排针：`GND GND 5V 5V GND GND`
> - 3.3V 供电排针：`3V3 3V3`
> - **板上没有 OLED 接口**

## 总表

| 功能 | 引脚 | 外设 / 模式 | 方向 | 说明 |
|---|---|---|---|---|
| 云台(上) 俯仰舵机 pitch | **PA8** | TIM1_CH1 | 输出 | 180° 舵机，50 Hz，500~2500 us |
| 云台(下) 旋转舵机 yaw | **PA11** | TIM1_CH4 | 输出 | 270° 舵机，50 Hz，500~2500 us |
| K230 串口 TX | **PA2** | USART2_TX | 输出 | 接 K230 UART2_RX（GPIO45） |
| K230 串口 RX | **PA3** | USART2_RX | 输入 | 接 K230 UART2_TX（GPIO44） |
| 板间链路 TX | **PA9** | USART1_TX | 输出 | 发「云台 yaw 偏角」给循迹板，30 ms 一帧 |
| 板间链路 RX | **PA10** | —（未配置） | 输入 | 排针上有，本工程只发不收 |
| 蜂鸣器 | **PB4** | GPIO（仅宏，无驱动） | 输出 | 3V3/PB4/GND，当前不初始化 |
| OLED SCL（保留） | **PB12** | GPIO 开漏（软件 I2C） | 输出 | 板上无 OLED 座，需飞线 |
| OLED SDA（保留） | **PB13** | GPIO 开漏（软件 I2C） | 双向 | 板上无 OLED 座，需飞线 |

代码里真正配置成外设的只有 **PA8、PA11（TIM1）、PA2/PA3（USART2）、PA9（USART1）**；
PB4、PB12、PB13 目前只登记了宏，没有初始化。

## K230 串口（4 针：5V / GND / PA3 / PA2）

| K230D BOX | 方向 | STM32 / 排针 |
|---|---|---|
| UART2_TX（GPIO44） | → | PA3（USART2_RX，丝印 RX） |
| UART2_RX（GPIO45） | ← | PA2（USART2_TX，丝印 TX） |
| 5V | — | 排针 5V |
| GND | — | 排针 GND |

- 115200-8-N-1，中断接收 + 255 字节环形缓冲。
- 丝印上方的 `RX TX` 对应 PA3 / PA2 两针，即 **PA3=RX、PA2=TX**，与代码一致。
- **必须共地**。不共地时串口电平没有共同参考，表现为随机乱码或完全收不到。

## 两路舵机（云台(上) / 云台(下)）

| PCB 丝印 | 引脚 | 定时器通道 | 代码里的轴 | 行程 |
|---|---|---|---|---|
| 云台(上) | **PA8** | TIM1_CH1 | pitch（上下俯仰） | 180° |
| 云台(下) | **PA11** | TIM1_CH4 | yaw（左右旋转） | 270° |

- 舵机电源走排针 **5V**，信号 3.3V 即可（舵机高电平门限通常 2.0~2.5 V）。
- 两路都必须是 `GPIO_Mode_AF_PP`，配成普通推挽就没有波形。
- 时基：PSC = 72-1、ARR = 20000-1 → 1 计数 = 1 us，20 ms 周期（50 Hz）。
- **TIM1 是高级定时器**：`bsp_servo_pwm.c` 在 `TIM_Cmd` 之后调用了
  `TIM_CtrlPWMOutputs(TIM1, ENABLE)` 打开 MOE，否则 PA8/PA11 上永远没有波形。

> ✅ **已确认（用户按实物确认，不是推断）**：
> 云台(上) = **PA8** = TIM1_CH1 = **180° 俯仰（pitch）**；
> 云台(下) = **PA11** = TIM1_CH4 = **270° 左右旋转（yaw）**。
> 排查提示：若将来更换舵机接线导致两个轴对调，只需把 `pin_config.h` 里的
> `BOARD_SERVO_YAW_PIN` / `BOARD_SERVO_PITCH_PIN`
> 和 `board_config.h` 里的 `BOARD_SERVO_YAW_CHANNEL` / `BOARD_SERVO_PITCH_CHANNEL`
> 两两对调（PA11↔PA8、CH4↔CH1），**不要改 PID 参数、不要改限幅**。

## 板间通信（4 针：PA9 / PA10 / GND / 3V3）

| 本板 | 方向 | 循迹板 |
|---|---|---|
| PA9（USART1_TX，丝印 TX） | → | PA10（USART1_RX） |
| PA10（丝印 RX） | ← | （本工程不接、不配置） |
| GND | — | GND |
| 3V3 | — | 3V3（可选，仅作参考电平） |

- 只发不收：USART1 只初始化 TX，115200-8-N-1，30 ms 一帧（13 字节、type=0x02、XOR 校验）。
- 板上虽然把 PA10 引出来了，但本工程用不到；将来若要收数据，把 USART1 改成
  `USART_Mode_Rx | USART_Mode_Tx` 并补 RX 中断即可。

## 蜂鸣器（3 针：3V3 / PB4 / GND）

| 排针 | 引脚 | 说明 |
|---|---|---|
| 3V3 | — | 蜂鸣器电源（有源蜂鸣器） |
| 信号 | **PB4** | `BOARD_BUZZER_PIN` |
| GND | — | 共地 |

- 代码里只有引脚宏（`BOARD_BUZZER_GPIO` / `BOARD_BUZZER_PIN` / `BOARD_BUZZER_GPIO_CLK`），
  **没有驱动代码**，上电不会响，也不会初始化这个脚。
- ⚠️ **PB4 复位后是 JTAG 的 NJTRST**。将来写驱动时必须先
  `GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE)`（保留 SWD），
  否则配置成普通 IO 也读不到/驱不动。

## OLED（可选，板上无座，需飞线）

板上**没有 OLED 接口**。`pin_config.h` 里仍保留 PB12/PB13 的宏，是为了不改动
`modules/oled.c` 与 `bsp/bsp_soft_i2c.c` 的接口；实际不接线时 OLED 初始化只是
在两个空闲脚上做开漏输出，不影响其他功能。

| OLED 模块 | 接到 |
|---|---|
| VCC | 3V3（排针） |
| GND | GND（排针） |
| SCL | PB12（闲置排针 B 组） |
| SDA | PB13（闲置排针 B 组） |

> 飞线时注意 PB12/PB13 同时列在「闲置排针 B 组」里，接 OLED 前确认没有别的功能占着。
> OLED 刷一屏约 3~5 ms，代码里已按 100 ms 节流，不要放进 10 ms 控制节拍。

## 供电

| 排针 | 用途 |
|---|---|
| `GND GND 5V 5V GND GND` | 舵机（两路）、K230 模块；5V 来自板上稳压/外部输入 |
| `3V3 3V3` | 最小系统板 3.3V、蜂鸣器、OLED（若飞线）、板间通信参考电平 |

- 两个舵机同时动作时电流可达 1 A 以上，**5V 与 3.3V 必须共地**，且舵机电源不要从
  最小系统板的 3.3V 取。
- K230 走 5V；它的 UART 是 3.3V 电平，直接接 PA2/PA3 即可，不需要电平转换。
- 最小系统板由板上 3.3V 供电（排母插座），不要再从外部 3.3V 重复供电。

## 空闲引脚

| 分组 | 引脚 |
|---|---|
| 闲置排针 A 组 | PA4 PA5 PA6 PA7 PB0 PB1 PB10 PB11 PB7 PB8 |
| 闲置排针 B 组 | PA0 PA1 PB9 PB6 PB5 PA12 PB15 PB14 PB13 PB12 |

- PB12/PB13 已保留给 OLED 宏（见上），真正使用前先二选一。
- **PA13/PA14 是 SWDIO/SWCLK 调试口**，不要占用；**PB2 是 BOOT1**，上电时不要被外部拉高。
- PA0~PA7、PB0、PB1 是 TTa（不容忍 5V），A 组排针上的 PA4~PA7、PB0/PB1 接 5V 信号前要分压。

## 坑与约束

1. **TIM1 的 MOE**：高级定时器不打开 `TIM_CtrlPWMOutputs` 就没有输出，
   这是本次改板最容易踩的坑，现象是「代码全对、示波器全平」。
2. **PA8/PA11 只有 TIM1 复用**：这两个脚没有别的定时器通道，换回 TIM2 是不可能的；
   TIM1 在 **APB2**，时钟宏是 `RCC_APB2Periph_TIM1`（不是 APB1）。
3. **云台(上)/(下) 的轴对应已确认**：上=PA8/TIM1_CH1/pitch/180°，
   下=PA11/TIM1_CH4/yaw/270°。只有将来改舵机接线导致轴对调时，才对调两个
   PIN/CHANNEL 宏，控制参数（Kp/Ki/Kd、限幅、中点）一律不动。
4. **板上无 OLED**：宏保留，但必须飞线 3V3/GND/SCL/SDA 才能显示。
5. **蜂鸣器 PB4 只有引脚宏、没有驱动**，且 PB4 是 JTAG 的 NJTRST，写驱动前先关 JTAG（保留 SWD）。
6. **K230 与板间通信都必须共地**；5V 排针给舵机和 K230，3.3V 排针给最小系统板和 OLED。
7. **PA2/PA3 同时是 USART2 与 TIM2_CH3/CH4 的复用脚**，本工程把 TIM2 让给了串口；
   改回 TIM2 会直接和 K230 串口打架。
